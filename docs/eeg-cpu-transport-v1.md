# EEG digest-pinned CPU transport v1

`tools/xtos_eeg_loop/inference.py` exposes `infer_window(binding, record, socket_path, request_id, deadline_ms, *, now_ns=time.monotonic_ns)`. This is a one-window transport component, not the eventual streaming lifecycle/approval owner. It accepts a validated ModelBinding, decoded native window and explicit CPU socket/deadline. It calls the existing strict feature validator/preparer and actual AF_UNIX client. The request pins both model name and SHA-256. No callable request injection is part of its production API.

Validate the record at current CLOCK_MONOTONIC time before any service call. Invalid feature/binding returns a machine-readable rejected/no_action result with output null and performs no network I/O. Send the prepared immutable values through the production client with a bounded socket timeout derived from deadline_ms (allow a small bounded framing margin). Recheck current monotonic time on return: clock regression, oldest-frame age expiration or elapsed total request budget expiration discards inference output. A transport error, malformed or conflicting peer response, no_action service response, wrong output shape/nonfinite/invalid probabilities also yields top-level no_action with output null and a fixed reason. Require successful output exactly one row of three finite float32 probabilities in [0,1] with sum within 1e-5 of one; this fixed transport fixture contract is explicit, not a generic model output interpreter.

Success status `transport_verified` carries model,model_sha256,request_id,source_kind,session_id,stream_generation,config_generation,window_id,barrier_id, input feature digest, completed_at_ns and a copied three-probability output. Top-level safe_action ALWAYS `no_action`; reason `transport_only`. Fixture/synthetic/SERDEV labels confer no action authority. A source bit is not authenticated hardware. Failure status is `rejected` with fixed reason, request_id when valid, safe_action=no_action and output null. Input feature digest binds the validated immutable prepared values and identities via deterministic finite JSON, never mutable caller objects.

This bounded call does not observe asynchronous stream events, suppress replay, create action candidates or consume approvals. The following lifecycle owner must coordinate native barrier/summary events and concurrent invalidation, and prevent a returned transport result from becoming a stale candidate. Tests must prove missing service, wrong model digest, malformed response, before/after freshness and output rejection. Actual integration must drive production native main+SDK+adapter syscall fixture, native serialized record, feature binding and signed real CPU child over actual AF_UNIX. The native command emits a terminal stop barrier/summary; integration must read and retain them and grant no action after stop. Three ordinary source units passing separately do not establish this interoperation.
