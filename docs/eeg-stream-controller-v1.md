# EEG stream controller v1

This integration slice owns native event ordering across reviewed one-window inference, StreamFence and SimulationFeedback. It introduces no real actuator, model training, authenticated physical-device identity or public release. Implement only after prerequisite component SPEC and QUALITY gates pass at current hashes. The controller runs as a library in a trusted local process; a stream of externally supplied JSON is not an authentication credential. Its blocking infer call and concurrently callable event handler are separate APIs so stop/gap/EOF can invalidate work while inference is running. Final JSONL process I/O wiring and artifact acceptance remain separate.

`StreamController(binding, socket_path, simulation, *, now_ns=time.monotonic_ns)` validates/owns its binding, fixed socket path and trusted SimulationFeedback object and owns one RLock and StreamFence. No injectable inference/approval/executor callbacks in the production API. `handle(record)` accepts a decoded exact native window/barrier/summary; `infer(record,request_id,deadline_ms,*,candidate_ttl_ms=1000)` performs one actual pinned CPU request; `confirm(candidate,nonce)` delegates the existing simulation confirmation; `approval_request(candidate)` exposes a fresh bound request through the existing simulator. `eof()` and `close(reason)` invalidate and terminal-close all pending work. Returned controller result is immutable/owned with safe_action=no_action and no reusable executable-authority flag.

Keep native windows' entire exact schema, not just the first window seen. `handle(window)` may validate/update tracking but MUST NOT reserve/consume an inference window; a later infer of the same record must remain possible. Avoid implementing separate window-tracking that can disagree with StreamFence; handle may reject direct windows with an explicit use-infer result instead. `handle(barrier)` validates exactly schema/session_id/barrier_id/reason/safe_action/physical_acceptance using native barrier schema. Session/barrier are exact positive uint64; reason bounded printable ASCII; safe_action=no_action and physical_acceptance=false. A valid non-regressing barrier invokes lifecycle.invalidate and simulation.invalidate under owner lock. Delayed regressing barriers are rejected without revoking healthy work, matching StreamFence stale-event semantics. Exact duplicate invalidation is idempotent. Unknown schema, malformed event or invalid window input revokes pending lifecycle and simulation state before refusing. A valid terminal summary checks exact schema/status/reason/windows_emitted/session_id/barrier_id/safe_action/physical_acceptance (native statuses complete/degraded/interrupted/error, bounded counters/reasons); it always closes, including a normal complete summary. Stop/cancel barriers revoke immediately; summary or EOF is terminal. Caller must deliver all records and EOF; successfully inferring an isolated recorded window does not prove the stream is active.

`infer` copies and validates the input window before network I/O, reserves an exact lease under owner lock, and revokes any previous candidate only when an accepted new reservation or invalid input changes state. A same-continuity busy reservation must leave the in-flight lease and pending state unchanged. Valid newer barriers/session may replace the lease; stale events or stale windows must not clear healthy replacement state. No lock held during blocking inference or trusted approval-store I/O. The inference request uses the identical PreparedInference snapshot (including prepared_at_ns) that the lease owns, so feature_digest from transport must equal the lease's canonical feature digest. Without changing frozen infer_window API, supply an internal clock closure returning lease.prepared.prepared_at_ns for its first validation call, then the actual trusted now_ns for all following observations. Supply a copied owned record whose fields were validated by reserve. This is internal time alignment, not a request-selected clock. Never mask or regenerate completed_at_ns to fit a candidate.

When the pinned request returns, acquire owner lock and complete the exact lease once at real current monotonic time. Only window_current plus exact transport_verified/no_action and matching digest/identities may be offered to SimulationFeedback; any rejected/obsolete result has no candidate/output authority. A stale completion must not clear a newer candidate/lease. Before offer, confirm this result is still the current controller revision and there is no queued invalidation that has already acquired the owner lock. Synthetic results remain transport evidence only and never yield a simulation candidate. SERDEV-labelled results may yield only an unverified software simulation candidate; no physical-device claim. All failures keep safe_action=no_action. An inference refusal for the exact active lease invalidates that continuity and any pending candidate; it cannot revoke an unrelated newer lease. Exceptions must not strand active ownership.

`confirm` must not hold controller lock across ActionGate storage operations, because event handlers need bounded access to revoke while approval is pending. SimulationFeedback's fixed callback lock serializes with invalidate/close and checks exact candidate once; no additional arbitrary executor injection. Model inference does not approve. A controller request consumer obtains explicit confirmation through the trusted ActionGate management authority, which remains separate. An actor string or source bit never substitutes for that authority.

Integration tests use the actual AF_UNIX client and signed16-input CPU service. For concurrency, Event-control a real socket proxy's forwarding of a valid response, deliver production native barriers/EOF/summary before releasing the response, then require no candidate and no output/action escape. Use exact native main+adapter+SDK syscall fixture to produce window/barrier/summary records and feed every terminal record; source remains synthetic. Positive SERDEV simulation is explicitly a labelled fixture input with real ActionGate+FixtureStore, never physical evidence. Cover fresh success, malformed/duplicate JSON record decoding if a decoder is added, wrong digest, busy preserving active, old completion preserving replacement, cancellation during real inference, revoked/expired confirmation, simultaneous confirmation, EOF before response, normal completion terminal, and no ignored summary. Keep shutdown/join/reaping and complete raw evidence. Preserve legacy four-feature fixture behavior separately. Parent owns shared maintenance/build/install/SBOM and source/guest acceptance after independent integration review.
