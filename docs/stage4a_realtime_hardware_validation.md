## 待真实硬件执行的测试

### 硬件要求

- **平台**: x86_64 服务器或工作站（裸机，非虚拟机）
- **CPU**: 多核处理器（≥4 核），至少 2 核可用于隔离
- **内存**: 8GB+
- **操作系统**: 部署 XTOS 构建的 Linux 6.6.0-rt15 内核

### 测试计划

#### 第一阶段：系统配置（1-2 小时）

1. 部署 XTOS 内核到真实硬件
2. 运行 `rt_system_check.sh` 检查基线配置
3. 应用优化配置（内核参数、运行时设置）
4. 重启并验证配置生效

#### 第二阶段：短时验证（1 小时）

```bash
sudo ./rt_cyclictest.sh \
    --duration 3600 \
    --threads 2 \
    --affinity 2,3 \
    --priority 80
```

验证测试框架工作正常，初步评估延迟范围。

#### 第三阶段：长时间测试（24 小时）

```bash
sudo ./rt_cyclictest.sh \
    --duration 86400 \
    --threads 2 \
    --affinity 2,3 \
    --priority 80
```

**关键指标**:
- 最大延迟（Max latency）< 100 us → 硬实时能力
- 平均延迟（Avg latency）< 10 us → 良好典型性能
- 延迟抖动（Range）< 50 us → 稳定性

#### 第四阶段：压力测试（可选，2-4 小时）

在后台运行负载：

```bash
stress-ng --cpu 4 --io 2 --vm 1 --vm-bytes 1G --timeout 7200s
```

同时运行 cyclictest，验证抗干扰能力。

### 结果归档

测试完成后：

1. 运行 `rt_analyze.py` 生成报告
2. 将结果复制到 `docs/rt-validation-results/`（本地保存，不推送 GitHub）
3. 记录硬件配置信息
4. 更新 `STATUS.md` 和开发计划

## 预期结果

### 旧版预期标准（历史记录，非当前验收标准）

在真实硬件上，经过适当配置的 XTOS 6.6.0-rt15 内核应达到：

- **最大延迟**: < 50 us（优秀），< 100 us（合格）
- **平均延迟**: < 10 us
- **测试持续时间**: 24 小时无异常

### 风险和缓解

| 风险 | 缓解措施 |
|-----|---------|
| 硬件不支持实时特性 | 检查 BIOS 设置，禁用节能特性 |
| 延迟过高（> 100 us） | 检查中断亲和性、禁用不必要服务 |
| 测试中断 | 在 screen/tmux 中运行，允许重连 |
| 环境干扰 | 隔离测试机器，最小化网络和磁盘活动 |
