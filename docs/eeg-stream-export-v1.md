# EEG window export v1

This P3 component exposes the reviewed integer-frame adapter as a bounded native command. It carries no inference or action authority. The executable is `eeg-stream`, built in `tools/xtos-eeg-stream/`.

## Invocation and lifecycle

`eeg-stream --device PATH --session-id N --window N --hop N --max-age-ns N --duration-ms N --max-windows N` requires every option exactly once. Decimal integers have no signs, whitespace or trailing characters. Session ID and receive age are positive uint64 values; window is 2..4096, hop 1..window, duration 1..600000 ms and maximum windows 1..100000. Device path must be nonempty and absolute. Channel count and rate are the P2 eight-channel, 250 Hz contract. Unknown, duplicate, missing or malformed options fail before opening a device.

The command owns its SDK session and START/STOP lifecycle. It initializes fixed adapter storage, creates the real SDK session, starts acquisition, then reads capacity 1 frame with NONBLOCK. Reading one frame per extraction opportunity avoids discarding intermediate window/hop emission opportunities. It uses actual CLOCK_MONOTONIC receive age and current time. EAGAIN waits at most a short bounded sleep and retries within the overall duration. It emits at most the requested number of windows. Every adapter barrier change emits an explicit invalidation record before any later window. A malformed batch, nontransient read error, stale window or disabled configuration terminates with a degraded result after cleanup; no later feature is published from that failed lifecycle.

Completion requires the requested number of windows before the duration expires, successful STOP and error-free output flush. SIGINT/SIGTERM are cancellation: preserve previously written records, invalidate the adapter, attempt STOP and destroy, and return a nonzero interrupted status. Any attempted START is followed by a STOP attempt, including START errors; SDK destroy still runs on errors. Preserve the primary failure when cleanup also fails, report cleanup failure explicitly, and never call a failed STOP complete. A signal handler only sets sig_atomic_t state; cleanup is performed in the main control flow. Device faults, cancellation, duration exhaustion and output errors must return in bounded time without claiming acquisition completion.

Exit statuses: 0 complete, 2 options, 3 device/setup, 4 degraded/timeout/cancelled/cleanup, 5 stdout failure. stderr holds concise diagnostics; stdout contains JSONL records only. Explicitly test /dev/full so buffered final-flush failure cannot be mistaken for success. All records have safe_action `no_action` and physical_acceptance false. The SERDEV source flag alone is not authenticated hardware evidence.

## JSONL contract

A window record contains exactly these fields: schema=`xtos.eeg.window.v1`, feature_mapping=`xtos.eeg.mean-rms.v1`, unit=`microvolt`, order=`mean_then_rms`, channels=8, sample_rate_hz=250, enabled_mask, frame_count, window_frames, hop_frames, max_receive_age_ns, emitted_at_ns, source_flags, source_kind (`serdev` or `synthetic`), barrier_id, session_id, stream_generation, config_generation, window_id, first_sequence, last_sequence, first_host_rx_ns, last_host_rx_ns, values (16 finite numbers), safe_action=`no_action`, physical_acceptance=false. Numeric metadata retains exact uint64 decimal values; do not serialize via double. Each value is derived from the actual reviewed adapter output. Means occupy 0..7, RMS including DC occupies 8..15. Disabled positions remain zero and retain the explicit mask. No hidden filter or rescaling occurs. Equal receive observations are valid.

An invalidation record has schema=`xtos.eeg.barrier.v1`, session_id, barrier_id, reason (fixed internal string), safe_action=`no_action`, physical_acceptance=false. A terminal summary has schema=`xtos.eeg.stream-summary.v1`, status (`complete`, `degraded`, `interrupted`, `error`), reason (fixed internal string), windows_emitted, session_id, barrier_id, safe_action=`no_action`, physical_acceptance=false. Summary is emitted only after cleanup status is known. Output failure is reported on stderr and cannot be repaired by printing a success summary.

Validate serializer metadata, finite values, sequence span, source, options and oldest-frame age before writing any bytes. Invalid feature input returns a negative errno and writes nothing. Implement serialization using a bounded local buffer or a fully validated snapshot; never emit a valid-looking prefix from malformed metadata. One caller serializes output and state. Public implementation helpers live in separate `eeg_export.[ch]`; keep the already reviewed adapter/window files unchanged.

## Verification boundary

Execute the actual command main, adapter, SDK session and window implementation. Wrap only OS device syscalls and controlled fault boundaries; successful session fixtures use a real disposable descriptor. Cover complete numerical/source JSON, strict options/no-open, insufficient frames/deadline, EAGAIN recovery, bad tail, disconnect, stale data, STOP failure, START failure cleanup, SIGINT/SIGTERM after accepted data and /dev/full. Retain RED then GREEN source/commands/logs for each behavior increment and run strict warnings plus ASan/UBSan. Preserve existing 10-method adapter suite. Disposable Makefile build/install plus an installed-only client are separate packaging evidence; real Linux guest and physical acquisition are later gates. No P3 phase acceptance follows from source/host fixtures.
