================================================================================
ARCHITECTURE
================================================================================

User Space:     [Applications] → libxtos-bci → ioctl/mmap
                                      ↓
Kernel Space:   Character Device (/dev/xtosX)
                      ↓
                xtos_bci_core (framework)
                      ↓
                Ring Buffer (DMA, zero-copy)
                      ↓
                Device Drivers (openbci_cyton)
                      ↓
Hardware:       Serial/USB/BT → EEG Devices

Data Flow:
  Hardware → Serial ISR → Work Queue → Packet Parser
    → Ring Buffer Write → Wake Wait Queue → User Read/mmap

================================================================================
TECHNICAL SPECIFICATIONS
================================================================================

Performance:
  - Latency: <2ms (acquisition to kernel buffer)
  - Throughput: 256 KB/s (8 channels × 1kHz × 4 bytes)
  - CPU overhead: Minimal (atomic ops, no memcpy)
  - Memory: ~16 KB per device (configurable)

Synchronization:
  - Spinlock for ring buffer write pointer
  - Wait queue for blocking reads
  - Atomic counters for statistics
  - Per-device spinlock for state

OpenBCI Cyton Specs:
  - Channels: 8 × 24-bit ADC (ADS1299)
  - Sampling rate: 250/500/1000/2000 Hz
  - Input range: ±187.5 mV
  - Interface: Serial 115200 baud
  - Packet format: 33 bytes (0xA0 start byte)
